Important CSS Concepts

CSS plays a major role in designing attractive and responsive webpages.

What is CSS and why is it used?

CSS stands for Cascading Style Sheets. It is used to control the appearance of webpages. With CSS, developers can change colors, fonts, layouts, spacing, and many other visual effects. It helps make webpages attractive and user friendly.

What are the three types of CSS?

CSS can be added to a webpage in three different ways.

  • Inline CSS – Written inside the HTML element.
  • Internal CSS – Written inside the style tag.
  • External CSS – Written in a separate CSS file.

Difference between Inline, Internal and External CSS

Type Usage
Inline CSS Styles are added directly inside HTML elements.
Internal CSS Styles are written inside the head section using style tag.
External CSS Styles are stored in a separate CSS file and linked to HTML.

Which CSS type has the highest priority?

Inline CSS has the highest priority because the styles are applied directly to the element itself.

Which CSS method is mostly used in real-time projects?

External CSS is widely used in real-world projects because it keeps the code organized and makes styling easier to manage.

What are CSS selectors?

CSS selectors are patterns used to select HTML elements and apply styles to them. Examples include element selectors, class selectors, ID selectors, and universal selectors.

Difference between class selector and ID selector

Class Selector ID Selector
Uses dot (.) symbol Uses hash (#) symbol
Can be used for multiple elements Used for a unique element

Purpose of universal selector in CSS

The universal selector is represented using an asterisk (*). It selects all elements present in the webpage.

What is cascading in CSS?

Cascading refers to the process where multiple styles are applied to an element. The browser decides which style should be applied based on priority rules.

What is specificity in CSS?

Specificity is the rule that determines which CSS style has more importance. Inline styles usually have higher specificity than class or element selectors.

Difference between block and inline elements

Block Elements Inline Elements
Occupy full width Occupy only required width
Start on a new line Do not start on a new line
Examples: div, p, h1 Examples: span, a, b

What is Flexbox and why is it used?

Flexbox is a CSS layout model that helps arrange items in rows or columns. It is mainly used for creating responsive and flexible webpage layouts.

Difference between justify-content and align-items

Property Purpose
justify-content Aligns items horizontally inside the container.
align-items Aligns items vertically inside the container.

Difference between px, em, rem and percentage units

  • px – Fixed measurement unit.
  • em – Relative to parent element size.
  • rem – Relative to root element size.
  • % – Relative to parent element dimension.

Difference between RGB, RGBA and HEX colors

Color Format Description
RGB Uses Red, Green and Blue color values.
RGBA Same as RGB but includes transparency using Alpha value.
HEX Uses hexadecimal values to represent colors.
