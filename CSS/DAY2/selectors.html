Webpage Styling Techniques

HTML is used to create the structure of webpages while CSS is used to style and design the webpage elements.

CSS selectors help developers target specific HTML elements and apply different styles to them.

External CSS is written in a separate file and connected to the HTML document using the link tag.

Different selectors are used for different purposes such as styling groups, unique elements and nested elements.
