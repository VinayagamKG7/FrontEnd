About HTML5

HTML5 is the latest version of HyperText Markup Language used to structure content on the web. It provides modern features for building responsive and interactive websites without relying heavily on external technologies. HTML5 introduced semantic elements, multimedia support, improved forms, and APIs that help developers create efficient web applications.

Modern websites use HTML5 because it improves accessibility, search engine optimization, user experience, and browser compatibility. HTML5 allows developers to organize content clearly using meaningful tags such as <header>,<section>,<article>and <Footer>

Quick Information

HTML5 supports multimedia tags like audio and video directly in the browser, reducing the need for external plugins.

Block and Inline Level Elements

Block Level Elements

Block level elements always start on a new line and occupy the full width available. These elements are commonly used to structure the layout of a webpage.

Examples of Block Level Elements

  • div
  • section
  • article
  • header
  • footer
  • nav
  • p
  • table

Inline Elements

Inline elements do not start on a new line. They only occupy the space required by their content. These are mostly used within text content.

Example Includes  : span,strong,em,mark,anchor Tagand code

Non-Semantic Elements

Non-semantic elements do not describe the meaning of their content. They are mainly used for grouping and styling purposes.

Examples of Non-Semantic Tags

  • div
  • span

The div tag is commonly used as a container element, while the span tag is used for inline grouping.

HTML Attributes

Attributes provide additional information about HTML elements. They are written inside the opening tag.

Commonly Used Attributes

  1. id – identifies a unique element.
  2. class – groups multiple elements together.
  3. href – specifies the destination URL.
  4. src – specifies the source of media files.
  5. alt – provides alternate text for images.
  6. title – displays extra information as a tooltip.
  7. target – defines where a linked document opens.
  8. placeholder – displays temporary input text.
  9. required – makes form fields mandatory.
