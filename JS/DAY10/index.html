Tasks 2

            const movie = () => {
                let collection = 800;
                console.log("Inside function:", collection);
            };

           movie();
           console.log(collection);

collection is created using let inside the function, so it exists only inside that function (function scope). Outside the function it cannot be accessed.

Tasks 3

            if (true) {

                var actor1 = "Ajith";

                let actor2 = "Vijay";
            }
            console.log(actor1);
            console.log(actor2);

var does not follow block scope, so actor1 can be accessed outside.

let follows block scope, so actor2 exists only inside the if block.
